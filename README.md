SIRMAX

**Sistema Integral de Registros Municipales y Administración eXtensible.**

SIRMAX es una plataforma **open source, local-first y orientada a municipios** para gestionar en un solo lugar servicios, trámites, registros ciudadanos, expedientes, documentos, facturación, pagos, caja, reportes, auditoría y copias de seguridad.

Diseñada inicialmente para **ayuntamientos de República Dominicana**, su arquitectura está preparada para adaptarse a diferentes municipios, países, monedas, normativas y modelos administrativos.

### ¿Qué busca resolver SIRMAX?

Los ayuntamientos suelen trabajar con procesos fragmentados, formularios manuales, documentos físicos y múltiples sistemas desconectados. SIRMAX busca convertir esos procesos en una experiencia única, rápida y fácil de utilizar.

El sistema está diseñado bajo una filosofía:

**Simple para el usuario. Potente para la administración. Abierto para la comunidad.**

### Principales características

* Gestión de ciudadanos y organizaciones.
* Catálogo configurable de servicios municipales.
* Gestión de trámites y expedientes.
* Requisitos y documentos por trámite.
* Facturación y recibos.
* Gestión de pagos y caja.
* Certificaciones y documentos administrativos.
* Gestión de propiedades y registros.
* Cementerios, mercados y otros servicios municipales.
* Inspecciones y tareas administrativas.
* Reportes y estadísticas.
* Auditoría completa de operaciones.
* Funcionamiento **offline / local-first**.
* Copias de seguridad locales.
* Copias de seguridad opcionales en Google Drive.
* Generación e impresión de documentos PDF.
* Sistema de usuarios, roles y permisos.
* Arquitectura preparada para múltiples municipios y países.

### Filosofía del proyecto

SIRMAX está construido para que una persona sin conocimientos técnicos pueda utilizarlo fácilmente, mientras que desarrolladores de todo el mundo puedan entender, colaborar, modificar y ampliar el código.

La experiencia del usuario es una prioridad fundamental.

El objetivo no es crear simplemente otro sistema administrativo, sino construir una plataforma municipal que sea:

**rápida · intuitiva · bonita · accesible · segura · modular · colaborativa**
