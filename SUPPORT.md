# Soporte de SIRMAX

## Para operadoras y personal municipal

1. **Documentación:** la guía de usuario (Docusaurus) cubre ciudadanos, servicios, trámites,
   facturación, pagos, caja, impresión, documentos oficiales, reportes, backup y restauración.
2. **Solución de problemas:** revisa la sección _Solución de problemas_ de la documentación.
3. Si el problema persiste, pide a la persona responsable de TI de tu municipio que abra un issue.

## Para personas usuarias técnicas y colaboradoras

| Necesito… | Dónde |
| --- | --- |
| Reportar un error reproducible | [Issues → Bug report](https://github.com/mrnoirhat/sirmax/issues/new?template=bug_report.yml) |
| Proponer una funcionalidad | [Issues → Feature request](https://github.com/mrnoirhat/sirmax/issues/new?template=feature_request.yml) |
| Hacer una pregunta o debatir una idea | [GitHub Discussions](https://github.com/mrnoirhat/sirmax/discussions) |
| Reportar una vulnerabilidad | [`SECURITY.md`](./SECURITY.md) — **no** uses issues públicos |
| Contribuir código | [`CONTRIBUTING.md`](./CONTRIBUTING.md) |

## Antes de abrir un issue

- Confirma que usas la última versión publicada o `main`.
- Busca si ya existe un issue abierto o cerrado con el mismo problema.
- Incluye: versión de SIRMAX, versión de Windows, modelo de impresora si aplica, pasos para
  reproducir, comportamiento esperado y observado, y capturas o logs cuando sea posible.

## Tiempos

Este es un proyecto open source mantenido por la comunidad. No hay un SLA de soporte comercial. Las
respuestas dependen de la disponibilidad de las personas mantenedoras.
